Sobre o acervo

O acervo digital do Rio Museu Olímpico é gerido pela equipe de catalogação utilizando a plataforma Tainacan, padrão IBRAM/IBICT/UnB para coleções museológicas. Todos os itens contam com metadados em conformidade com Dublin Core e podem ser consumidos via API REST aberta.
